# PadDisplay 0.2.0 原生 UI 实现与验证

日期：2026-10-13。以已确认的 [Liquid Glass 原型](design/macos-liquid-glass-v1/README.md) 实现原生 SwiftUI 界面，并按照后续反馈调整设备预览壁纸与手机外框。

## 实现范围

| 界面 | 实现 |
| --- | --- |
| 主窗口 | 原生 NavigationSplitView，设备连接状态、保存配置与实际输出区分；选择设备只查看配置 |
| 工具栏 | 全局自动匹配与一次恢复操作分开，使用系统工具栏和 macOS 26+ 玻璃按钮 |
| 设备预览 | 原创蓝紫流线壁纸，浅深色适配；iPad 默认横屏；iPhone 使用写实 PNG 机身，保留灵动岛、镜头和侧键，等比旋转 |
| 编辑浮层 | 值类型草稿、型号与方向、像素与 HiDPI 校验；保存才持久化，取消修改带确认 |
| 状态提示 | 权限、等待、准备、暂停、多连接、未知设备、伴侣冲突和恢复失败；未就绪不显示为成功 |
| 设置 | 登录项、自动匹配、系统外观说明、权限说明；标准 `⌘,` |
| 关于 | 独立原生窗口、实际版本、作者与账号、号码复制、本地 MIT 及素材权利说明 |
| 菜单栏 | 当前会话概要、自动匹配、恢复、继续、主窗口、设置、关于与退出 |

使用原生窗口、侧边栏、工具栏、表单和弹窗，不手绘系统窗口装饰。macOS 26+ 使用系统 `.glass` / `.glassProminent`，旧系统回退标准按钮。文字和背景使用系统语义颜色。

关于文案为：**作者：耳过清风 · 小红书号：5397290838。本软件开源免费，欢迎点赞与关注，支持作者持续更新。**版本读取包内 Info.plist，当前为 0.2.0。

## 安装包与现场状态

Release 构建、Info.plist 和 ad-hoc 签名检查通过。`dist/PadDisplay-0.2.0-arm64.zip` 包含原生应用、图标、写实手机 PNG、MIT 许可及素材说明；`dist/SHA256SUMS.txt` 保存 ZIP 校验值。安装包未替换 `/Applications/PadDisplay.app`。

[前后比对](../evidence/native-ui-20261013/preservation-check.json) 确认原安装二进制、自动匹配设置、两台设备配置及正式应用 / UU 进程均未变化。正式版 PID 97257 持续运行。

整个显示布局没有通过「不变」检查：测试期间出现真实的 iPad 远程会话，15:40:05 写入恢复记录，并新增 `PadDisplay · iPad Air (13 英寸, M2)` 虚拟屏，输出 2732 × 2048、逻辑 1366 × 1024。全部隔离验证实例退出后，该虚拟屏仍在；[正式版只读 AX 状态](../evidence/native-ui-20261013/installed-app.ax.txt) 确認正式版已识别 iPad 并维持此屏幕。实体 `LV273HUPR` 的输出像素与逻辑尺寸仍为 2560 × 1440 @ 30 Hz。记录此真实会话变化，不删除其恢复记录、不强制还原当前会话，也不将其计入 0.2.0 的显示切换验收。
